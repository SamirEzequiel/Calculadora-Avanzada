# 🧮 Calculadora Avanzada con Interfaz Gráfica (Tkinter)

Una calculadora avanzada en Python con **interfaz gráfica moderna**, funciones científicas y un **historial exportable**.

---

## 🚀 Características

✔ Operaciones básicas: suma, resta, multiplicación, división  
✔ Funciones avanzadas:  
   - Potencia (^)
   - Raíz cuadrada (√)
   - Seno, coseno, tangente
   - Logaritmo  
✔ Historial visible y exportable a `.txt`  
✔ Botón para **borrar historial**  
✔ **Memoria (M+, M-, MR)**  
✔ Modo **oscuro** (predeterminado)  
✔ Soporte para **atajos de teclado** (`Enter`, `Backspace`)  

---

## 🛠 Requisitos

- Python **3.8 o superior**
- Librerías:
  - `tkinter` (incluido con Python)
  - No requiere dependencias externas
